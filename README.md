# MobiStream

**Ultra-minimalist, 100% Pitch-Black AMOLED streaming application with Apple Liquid Glass frosted aesthetics and physical tactile haptics.**

Powered by the curated [MSR (MobiStream Repo)](https://github.com/buildbyrohit/msr) extension ecosystem.

---

### Highlights

* **True Pitch-Black AMOLED (`#000000`)**: Zero ambient backlight bleed; maximum battery efficiency.
* **Apple Liquid Glass**: Frosted translucency, specular rim highlights, and spring physics.
* **Tactile Haptic Engine**: Subtle, crisp physical feedback on all touches, switches, and cards.
* **Curated Hindi Providers**: Instant live streaming with direct shortcodes (`msr`, `jeet`, `rohit`, `mobistream`).
* **High-Performance Player**: ExoPlayer with hardware decoding, swipe gestures, and Cloudflare DNS-over-HTTPS.
